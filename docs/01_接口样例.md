### 10c. 【查不到样例】有校区，但半径内没有站点

**这是要求的那组「查不到站点、只返回 warnings」样例。**`items` 为空数组，`warnings` 说明数据覆盖不足。`poi_transport` 覆盖不齐（抽样 200 个校区仅 73% 能在 3 km 内找到交通点），所以「查不到」是常态——前端**绝不能**渲染成「该高校周边没有交通站点」。

请求：

```bash
curl "$BASE/api/colleges/2954/transport"
```

响应 `200`：

```json
{
  "items": [],
  "total": 0,
  "warnings": [
    "部分高校周边缺少交通设施数据"
  ]
}
```

### 10d. 【查不到样例】压根没有带几何的校区

两种「查不到」必须分开说：这条是「缺校区」，10c 是「缺交通数据」。全库 2,952 所高校只有 432 所有校区，前者是常见情况而非边缘情况，混成一条会把「缺校区」错说成「缺交通数据」。

请求：

```bash
curl "$BASE/api/colleges/4687/transport"
```

响应 `200`：

```json
  "items": [],
  "total": 0,
  "warnings": [
    "该校暂无可用校区数据，无法进行周边查询"
  ]
}
```

### 10e. 参数越界 -> 422

`mode` 只允许库内真实值 `rail / metro / airport / rail_halt`。越界一律 422，**不静默钳制、也不忽略**——宁可让调用方看见错误，也不要返回一个「看起来筛过了其实没筛」的结果。同样适用于 `radius_km > 20` 与 `limit > 200`。

请求：

```bash
curl "$BASE/api/colleges/3059/transport?mode=train"
```

响应 `422`：

```json
{
  "detail": "mode 只允许 ['rail', 'metro', 'airport', 'rail_halt']，收到非法值 ['train']"
}
```

## 附：需要倪嵩提供的服务函数接口

`/api/search`（莫炜钧总集成）不自己写招生 SQL，只调倪嵩的 service。约定如下，**签名已冻结，不要改**：

`app/services/admission_service.py`

| 函数 | 用途 | 返回 |
|---|---|---|
| `filter_school_ids(source_province, year, category, batch)` | `/api/search` 的招生子查询 | `None` = 没启用任何招生条件，调用方**不过滤**；`list[int]` = 只保留这些 school_id（空列表表示无匹配） |
| `filter_meta()` | `/api/meta/filters` 的五个下拉项 | `{years, source_provinces, edu_levels, categories, batches}`，全部取自库里 distinct |
| `list_admissions(school_id, source_province, year, category, batch, page, page_size)` | `/api/colleges/{id}/admissions` | `(items, total, display_deduplicated)` |

边界（附录 B）：数据链固定 **College → SchoolUnit → SchoolAdmission**；不要把 `EnrollmentPlan` 或 `MajorAdmission` 引进来；`category` / `batch` 是来源原始口径，不做全国统一映射。
